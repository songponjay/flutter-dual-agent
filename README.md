# Flutter Dual-Agent Learning System 🤖

ระบบสอน Flutter แบบ AI dual-agent — Teacher สอนทีละ step, Senior review โค้ด

## How it works

| Agent | หน้าที่ |
|---|---|
| 🎓 `/teacher` | สอนทีละ step พร้อมควิซ |
| 🔴🟡🟢 `/senior` | review โค้ดแบบ senior dev |
| 📊 `/dashboard` | ดู progress ทั้งหมด |

## Syllabus — DayDone AI App

Flutter + Riverpod + Clean Architecture + Claude/Gemini API

| Module | หัวข้อ | Status |
|---|---|---|
| 1 | Clean Architecture Scaffold | ✅ |
| 2 | Riverpod AsyncNotifier | ✅ |
| 3 | SQLite Offline Cache | ✅ |
| 4 | REST API + Retry | ✅ |
| 5 | AI Summary (Claude + Gemini) | ✅ |
| 6 | Dynamic Excel Export | ✅ |
| 7 | Auth Mock → Firebase | ✅ |
| 8 | Dark/Light Mode + Polish | ✅ |

## Stack

- **AI Agents:** Claude API (Anthropic) + Gemini API  
- **Prompts:** Teacher SOP, Senior Review, Quiz System
- **Tracking:** Markdown-based progress + quiz log
